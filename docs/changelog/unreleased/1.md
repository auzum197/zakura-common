## zakura-orchard

### Added

- Added the `address-signatures` feature, with off-chain spend-authority and
  receive-authority signatures for an Orchard address in
  `orchard::address_signature`
  ([#1](https://github.com/auzum197/zakura-common/pull/1)).

## zakura-halo2-gadgets

### Added

- Added `EccChip::configure_full_width_fixed_base_only`, which configures the ECC
  chip without the gates for fixed-base multiplication by a short scalar or by a
  base field element
  ([#1](https://github.com/auzum197/zakura-common/pull/1)).

## zakura-keys

### Added

- Added the `orchard-address-signatures` feature, which enables the
  `address-signatures` feature of `zakura-orchard`
  ([#1](https://github.com/auzum197/zakura-common/pull/1)).
